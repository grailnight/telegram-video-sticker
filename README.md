# Видеостикер для Telegram (Android)

Приложение конвертирует любое видео в формат видеостикера Telegram:

- WebM, кодек VP9, без звука
- одна сторона 512 px, вторая — не больше 512 (или квадрат 512×512 с обрезкой по центру)
- до 3 секунд, до 30 кадров/с
- размер до 256 КБ (битрейт подбирается автоматически, при необходимости перекодируется повторно)

## Как пользоваться

1. «Выбрать видео» (или «Поделиться» видео из галереи → «Видеостикер»).
2. Указать начало фрагмента и длину (до 3 с), при желании включить обрезку до квадрата.
3. «Конвертировать», затем «Сохранить…» или «Поделиться».
4. Отправить получившийся `.webm` файлом боту [@Stickers](https://t.me/Stickers) (`/newvideo` для нового набора).

## Сборка

Нужны JDK 17+ и Android SDK (platform 35, build-tools 35).

```
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk` (подписан debug-ключом, Android 8.0+).

## Как это устроено

Без ffmpeg: `MediaExtractor` → декодер → OpenGL (масштаб, поворот, обрезка) → системный кодировщик VP9 (`MediaCodec`) → `MediaMuxer` WebM. APK весит около 80 КБ. На устройстве должен быть кодировщик VP9 (есть на большинстве телефонов; если его нет, приложение об этом сообщит). Прозрачность не поддерживается.
